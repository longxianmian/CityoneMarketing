# CityOne Agent 模块第一步开发文档

## 目标：先把现有 Agent 管理端从“展示骨架”补成“可配置骨架”

## 一、开发原则

1. **不推翻现有页面骨架重做**

   * 必须基于当前已有的管理端菜单、页面路由、模块结构做增量开发。
   * 不允许另起一套新的 Agent 管理系统。

2. **第一步只做“可配置骨架”**

   * 先完成后台配置能力、数据表、保存与读取。
   * 先不做复杂自动执行链路。
   * 用户端问问先不做完整智能执行，只预留配置和前后端结构。

3. **必须保护当前可运行基线**

   * 不要大范围替换现有代码。
   * 必须优先在现有页面中定点补充模块。
   * 每个改动都要尽量可回退。

4. **多语言先保留结构**

   * 本步所有新增字段必须预留中/泰/英三语能力。
   * 即使当前先只录一套数据，字段结构也不能写死单语言。
