# CityOne Growth 三语方案全览

---

## 一、语言识别与切换机制

```
优先级：手动设置 > 浏览器语言 > 默认英语

存储 Key：
  cityone_growth_lang       → 当前语言（zh / th / en）
  cityone_growth_lang_mode  → 模式（auto / manual）

语言映射规则：
  zh* → zh（简体中文）
  th* → th（泰文）
  en* → en（英文，也是 fallback 兜底）
```

## 二、静态 UI 文本方案

**适用范围**：所有写死在界面上的固定标签、按钮、提示文案

**技术方式**：

```tsx
const { t, language } = useI18n()

t('welfare.title')       // → '福利中心' / 'ศูนย์สิทธิพิเศษ' / 'Benefits Center'
t('common.agent')        // → 'AiAgent'（三语一致）
t('mine.languageSub')    // → '切换中文、泰文、英文' / 'เปลี่ยนภาษา…'
```

**已翻译的五大模块（`src/i18n/index.tsx`）**：

| 模块 | 说明 | Key 数量 |
|---|---|---|
| `common` | 底栏导航、通用操作、积分/卡券标签 | ~25 |
| `welfare` | 首页 Banner 标题、分类标签、活动类型标签 | ~20 |
| `agent` | Agent 入口页标题、功能标签、说明文字 | ~8 |
| `detail` | 活动/产品详情页所有标签 | ~15 |
| `mine` | 我的页面所有菜单、副标题 | ~25 |
| `admin` | 后台管理所有页面（仅中文，后台不做多语） | 大量 |

**关键翻译词汇对照**：

| 中文 | 泰语 | 英语 |
|---|---|---|
| 福利中心 | ศูนย์สิทธิพิเศษ | Benefits Center |
| 首借福利季 | โปรยืมครั้งแรก | First-Time Borrowing Perks |
| 裂变 | การเติบโตแบบไวรัล | Viral Growth |
| 高转化 | อัตราแปลงสูง | High Conversion |
| AiAgent 助理 | ผู้ช่วย AI | AI Assistant |
| 积分兑换 | แลกคะแนน | Redeem Points |
| 我的卡券 | คูปองของฉัน | My Coupons |
| 去我的页面 | ไปที่หน้าของฉัน | Go to My Page |

## 三、动态内容方案

**适用范围**：从 API 获取的活动标题、描述、卡券名称等运营填写的内容

### 3.1 数据结构（三语对象）

后端存储格式，每个文本字段都是一个对象：

```json
{
  "title":       { "zh": "扫码领券活动", "th": "กิจกรรมสแกนรับคูปอง", "en": "Scan & Get Coupons" },
  "description": { "zh": "限时活动，先到先得", "th": "กิจกรรมจำกัดเวลา", "en": "Limited time offer" },
  "buttonText":  { "zh": "立即参与", "th": "เข้าร่วมเลย", "en": "Join Now" }
}
```

### 3.2 前端读取方式

```tsx
import { pickLocalizedText, useI18n } from '../../i18n'

const { language } = useI18n()

// 取当前语言的文本，自动降级：当前语言 → en → zh → th
const title = pickLocalizedText({ title: activity.title }, 'title', language)
```

**降级规则**：`当前语言 → en → zh → th → 空字符串`

### 3.3 已接入 pickLocalizedText 的页面

| 页面 | 动态字段 |
|---|---|
| `WelfareHomePage` | 活动/卡券 title、badge |
| `ActivityUserPage` | title, subTitle, description, highlights, participationGuide, rewardGuide, noticeText, buttonText |
| `CouponUserPage` | title, valueText, expireText |
| `RedeemUserPage` | title, subTitle, pointText, pickupText, highlights, description, usageGuide, noticeText, primaryText, secondaryText |
| `MinePage` | level, title, valueText, expireText, site, status, duration |
| `NearbyPage` | title, name, status |

## 四、AI 自动翻译方案（管理端录入时）

**触发时机**：管理员在后台保存活动/产品/落地页模板时，自动将中文内容翻译成泰语和英语

**接口**：`POST /api/translate`

```json
请求：
{
  "texts": {
    "title": "扫码领券活动",
    "description": "限时福利，先到先得"
  },
  "sourceLang": "zh"
}

响应：
{
  "result": {
    "title":       { "zh": "扫码领券活动", "th": "กิจกรรมสแกนรับคูปอง", "en": "Scan & Get Coupons" },
    "description": { "zh": "限时福利，先到先得", "th": "สิทธิ์จำกัดเวลา มาก่อนได้ก่อน", "en": "Limited-time perks — first come, first served" }
  }
}
```

**已集成自动翻译的管理页**：

| 管理页 | 触发方式 |
|---|---|
| `ActivityTemplateManage` | 点击「保存」时，检测空白语言版本自动补全 |
| `ProductTemplateManage` | 同上 |
| `LandingTemplateManage` | 同上 |
| `MultiLangInput` 组件 | 每个三语输入框内置「一键翻译」按钮 |

## 六、两种方案对比汇总

| 维度 | 静态 UI 文本 | 动态内容 |
|---|---|---|
| **数据来源** | 代码内 `i18n/index.tsx` | 后端 API 返回 |
| **翻译方式** | ChatGPT 人工审核后硬编码 | AI 自动翻译（保存时触发）|
| **读取方式** | `t('module.key')` | `pickLocalizedText(obj, field, lang)` |
| **数据结构** | 三棵树（zh/th/en 分支）| 每字段 `{zh, th, en}` 对象 |
| **降级逻辑** | 无（所有 key 必须存在）| `当前语言 → en → zh → th` |
| **更新成本** | 需改代码 + 重新部署 | 后台重新保存即可生效 |
| **适用内容** | 固定标签、按钮、菜单 | 活动标题、描述、卡券名称 |
