## 三、卡券创建操作步骤

**路径：** 福利中心 → 卡券 → 卡券创建 → 点击「新建」

### 必填字段

| 字段 | 说明 | 注意事项 |
|------|------|---------|
| **券名称** | 用户端展示的卡券标题 | 支持三语言自动翻译（填写后台切换语言后系统自动生成 TH/EN） |
| **输入语言** | 名称输入所用语言 | 默认中文；如直接输入泰语或英语可切换 |
| **券类型** | 见 2.1 | 必选，决定发放策略 |
| **优惠方式** | 见 2.2 | 必选，决定优惠逻辑 |
| **面额/折扣值** | 优惠金额或折扣率或分钟数 | `fixed`：填金额（如20）；`percent`：填折扣率（如0.8）；`free_time`：填分钟数（如30）；`free_order`：填0即可 |
| **发放总量** | 可领取总张数 | 填0视为不限量；限量时达到上限自动显示「已领完」 |

### 选填字段

| 字段 | 说明 |
|------|------|
| **使用门槛（THB）** | 最低消费金额，0 = 无门槛 |
| **生效时间 / 失效时间** | 不填默认长期有效 |
| **状态** | 生效中 / 停用；停用状态用户端不可见 |
| **适用站点范围** | 全部站点 或 指定站点（支持多选） |
| **封面图片** | 用户端卡券列表/详情展示图 |
| **封面视频** | 卡券详情页视频介绍 |

## 四、奖池管理（卡券作为游戏奖品）

**路径：** 福利中心 → 卡券 → 奖池管理

奖池管理让卡券与转盘、刮刮卡等游戏活动深度联动，每个活动/游戏玩法拥有独立的奖池配置。

### 奖品类型（3类）

| 类型 | 说明 |
|------|------|
| 🎫 卡券 | 体验券、折扣券 — 从已创建的卡券中选择 |
| 🛍️ 商品 | 数字商品、实物商品 — 从商品库中选择 |
| 🤍 谢谢参与 | 未中奖格，必须设置，确保概率总和 = 100% |

### 奖池配置项

| 字段 | 说明 |
|------|------|
| **奖品名称** | 转盘/刮卡上显示的文字 |
| **概率权重** | 相对权重（非百分比），系统自动换算；如设3个格：权重 10/10/80，则实际概率 10%/10%/80% |
| **库存数量** | -1 = 无限；正整数 = 限量 |
| **展示颜色** | 转盘扇形或刮刮卡格子的背景色 |
| **排序号** | 决定在游戏界面的显示顺序 |
| **状态** | 启用 / 停用（停用的奖品不参与抽奖） |

### 操作流程

```
1. 在「活动管理」中创建活动（转盘/刮刮卡类型）
2. 进入「奖池管理」，URL 自动关联活动ID
3. 添加奖品：选择卡券/商品，配置权重和库存
4. 务必添加「谢谢参与」格，确保兜底
5. 保存后活动上线，奖池立即生效
```

## 八、常见注意事项

1. **库存设为 0**：代表「不限量」，请谨慎使用，可能造成超量发放
2. **状态停用后**：用户端立即看不到该券，已领取的不受影响
3. **有效期必须配对**：生效时间和失效时间要同时填或同时不填
4. **同一用户只能领取一次**：系统自动防重复领取，无需手动控制
5. **奖池概率总和**：权重之和决定各格比例，转盘/刮卡至少要有一个「谢谢参与」格
6. **三语言翻译**：名称保存时系统自动调用翻译服务，泰语/英语用户看到对应语言
