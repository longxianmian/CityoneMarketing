# CityOne 营销增长系统

## 项目定位

本项目是 CityOne 共享充电宝体系中的独立营销增长引擎。

它不是 A 系统主业务的替代系统，也不是继续把 B 系统修成正式运营主系统，
而是一个通过旁路方式接入 A 系统的独立增长系统。

## 当前阶段目标

当前先建设 P0 共用底座，优先完成：

1. 统一增长入口层
2. 动态活动路由层
3. 新老客自动分流基础结构
4. LINE OA 关注回跳预留
5. A 系统桥接层骨架
6. 最小奖励底座骨架
7. 最小归因与埋点结构

## 开发原则

1. A 系统继续承担正式运营测试主链路
2. B 系统继续作为能力抽取来源
3. 营销增长系统必须独立建设
4. 所有拉新最终沉淀到 LINE OA
5. 所有活动统一走增长入口层
6. 所有奖励统一走奖励底座
7. 所有业务结果统一桥接 A 系统
8. 所有设计兼顾未来整合进 CityOne 主平台
