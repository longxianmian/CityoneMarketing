# CityOne 营销增长系统 P0 阶段成果说明

## 一、当前阶段定位

当前已完成营销增长系统后端 P0 基线搭建。

本阶段目标不是做完整营销系统，而是先把统一增长底座搭起来，确保后续活动、借电桥接、奖励发放、归因统计都建立在统一结构之上。

---

## 二、当前已完成内容

### P0-1 统一增长入口层
已完成统一入口解析接口：

- GET /api/entry/resolve

当前已支持统一接收以下核心参数：

- site_id
- entry_type
- entry_code
- user_id
- line_user_id
- feature_name
- referrer_type
- referrer_id
- utm_source
- utm_campaign

已区分两大入口场景：

- 活动场景入口
- 现场借电业务入口

### P0-2 动态活动路由层
已完成独立活动路由服务：

- backend/src/services/feature-router.js

当前支持：

1. feature_name 强制指定优先
2. site_id + entry_type 定向规则
3. entry_type 默认路由
4. system fallback 回退规则

当前已在返回中提供：

- feature_route_context.resolved_feature_name
- feature_route_context.route_source
- feature_route_context.forced_feature_name

## 六、当前阶段结论

当前 P0 已不是文档阶段，而是已经形成可运行后端基线。

后续所有功能开发，应继续坚持以下原则：

1. 所有入口统一走 entry 层
2. 所有活动统一走 feature 路由层
3. 所有新老客分流统一走 diversion 层
4. 所有 OA 回跳统一走 oa-router
5. 所有奖励统一走 reward-engine
6. 所有埋点统一走 event-tracker
7. 所有店员归因统一走 staff-attribution
8. 所有 A 系统桥接统一走 a-system-bridge
